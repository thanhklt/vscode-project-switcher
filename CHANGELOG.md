# Changelog

## 0.1.1

- Add Open in New Window to each saved project's right-click menu, opening a new window of the current IDE.

## 0.1.0

- Projects sidebar with persistent shared local folder bookmarks.
- Add folders, save current project, search, rename and remove entries.
- Open in the current window or a new window using standard VS Code APIs.
- Atomic storage, concurrent writer protection and automatic external refresh.
